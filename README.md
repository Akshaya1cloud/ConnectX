# ConnectX – Real-Time Video Conferencing Platform

ConnectX is a web-based video conferencing and collaboration platform designed to enable seamless online communication. It provides users with features such as video meetings, real-time messaging, screen sharing and interactive collaboration tools.

## Features

- User Registration and Login
- Create and Join Meetings
- Real-Time Audio and Video Communication
- Screen Sharing
- Real-Time Chat
- Interactive Whiteboard
- Camera and Microphone Controls
- Meeting Room Management

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Real-Time Communication:** WebRTC, Socket.IO
- **Development Tools:** Visual Studio Code, Git, GitHub

1. Clone the repository.
2. Install the required dependencies.

4. Start the backend server.
